## 1. 分析引擎：四层多因子框架 v1.6

### L1 — 宏观环境（三轨评分）

| 轨道 | 范围 | 评分区间 | 权重 | 核心指标 |
|:---|:---|:---:|:---:|:---|
| **US-L1** | 美国经济 | 1–5 | 0.50 | CPI/PCE, Fed利率, 美债收益率曲线, 非农 |
| **CN-L1** | 中国经济 | 1–5 | 0.35 | PMI, CPI/PPI, M2, 社融, 中美利差 |
| **JP-L1** | 日本经济 | 1–5 | 0.15 | JGB 10Y, USD/JPY, 日央行政策 |

L1 综合评分 = US×0.50 + CN×0.35 + JP×0.15

### L2 — 风格因子

| 因子 | 核心逻辑 | 数据源 |
|:---|---|:---|
| 动量 | 过去3个月收益排序 | TickFlow |
| 价值 | PE/PB分位数 | TickFlow / cn_financial_pro |
| 成长 | 营收/盈利增长趋势 | TickFlow 财务数据 |

### L3 — 市场情绪

| 维度 | 指标 |
|:---|---|
| 温度 | VIX, 黄金波动率, 比特币波动率 |
| 偏好 | ETF资金流向, 行业轮动 |
| 资金 | 北向资金, 两融余额, 中美利差 |

### L4 — 资产定位（五资产结构）

| 资产 | 代码 | 角色 | L1核心驱动 |
|:---|:---|:---|:---|
| A股大盘科技成长 | 159682 创业板50 | 🛡️进攻 | CN-L1 + 全球AI周期 |
| 美股科技 | 159632 纳斯达克ETF | 🛡️进攻 | US-L1 + Fed利率 |
| 黄金 | 博时黄金ETF联接C | 🛡️防御 | 实际利率 + DXY + 地缘 |
| A股高股息价值 | 南方红利低波50ETF联接A | 🛡️防御 | CN-L1 + 利率 |
| 跨境美元理财 | USDT稳定币 | 💰现金替代 | L1宏观 → 稳定币收益率 |

> ⚠️ 加密货币(BTC/ETH) 不再纳入 L4 量化分析，仅 L1 层评估宏观对稳定币理财收益率的影响。

### 评分 → 仓位映射

```
综合评分区间    仓位中枢
  1.0 – 1.5      10%   (极端防御)
  1.5 – 2.0      20%   (防御)
  2.0 – 2.5      35%   (偏防御)
  2.5 – 3.0      45%   (中性偏保守)
  3.0 – 3.5      55%   (中性偏进攻)
  3.5 – 4.0      70%   (进攻)
  4.0 – 5.0      85%   (积极进攻)
```

## 2. 执行层

### 交易执行系统 SOP

完整的交易流水线：信号触发 → 评分验证 → 仓位计算 → 订单生成 → 挂单执行 → 持仓记录 → 复盘评估。

### 加密日度操作指引

每日 BTC/ETH 监控流程：隔夜变化 → 技术面 → 资金面 → 链上数据 → 决策。

### 执行平台

**同花顺**，支持：
- 条件单（价格触发买入/卖出）
- 止损单（保护性止损）
- 无 Level-2 行情

## 7. 评估与校准周期

| 频率 | 任务 |
|:---|---:|
| 每日 | 开盘前/盘中巡检，加密监控 |
| 每周 | 评分更新，交易执行跟踪，纳指专项 |
| 每月 | 绩效 vs 基准对比，数据发布日检查 |
| 每季 | 框架校准（准确性、阈值、因子权重） |
| 每半年 | 方法论全面审查 |
| P&L触发 | 回撤>10% → 紧急审查；回撤>15% → 暂停交易 |

## 架构设计原则

1. **分层解耦** — 每层独立运作，层间通过评分接口通信
2. **多源交叉** — 所有结论至少2个数据源验证
3. **可证伪假设** — 每个评分与建议可回溯到原始数据
4. **逆向思维内置** — 芒格四模型贯穿分析流程
5. **安全边际优先** — 仓位中枢上限85%，回撤警戒线10%
6. **自愈机制** — 学习–校准–迭代闭环
