## 阶段六：产业链定位 (NVIDIA官方五层框架)

### 6.1 官方标准框架定位

| 层级 | 名称 | Spectrum-X CPO 定位 |
|:---:|:---|:---|
| 第1层 | 能源层 | 间接关联 — CPO每端口功耗从30W降至~9W(-70%)，减少数据中心总能耗 |
| **第2层** | **芯片层** | **核心关联** — 硅光引擎(MRM调制器+探测器)与交换ASIC共封装，台积电COUPE平台制造 |
| **第3层** | **基础设施层** | **主要所属层级** — 交换机是数据中心网络骨干，CPO将光引擎前移至交换机封装内 |
| 第4层 | 模型层 | 间接 — 更高效的网络支撑更大规模模型训练 |
| 第5层 | 应用层 | 间接 — 降低AI推理延迟，提升应用体验 |

**结论**: Spectrum-X CPO交换机横跨**第2层(芯片)+第3层(基础设施)**的交界点，将传统分立式光模块(第2-3层之间的独立器件)直接整合进交换机ASIC封装内。

### 6.2 不可绕过的物理连接点

**物理刚性约束**: 
- **台积电COUPE平台** — NVIDIA Spectrum-X的硅光引擎(PIC+EIC)必须通过台积电65nm硅光工艺+3D堆叠封装制造。**全球仅有台积电具备此量产能力。**
- **外部激光源(ELS)** — CPO交换机仍需高功率外置激光器作为光源，激光器芯片(磷化铟/砷化镓)受物理材料限制，无法绕过。
- **光纤连接单元** — 从交换机面板到外部网络的光纤物理连接不可绕过(MPO/MMC连接器)。

## 阶段6B：产业链瓶颈分析

### 6B.1 CPO交换机产业链拆解

```
[NVIDIA全栈设计]
    ↓
[台积电COUPE制造] ← ⚠️ 关键瓶颈
    ├── PIC (65nm 硅光工艺): MRM调制器 + 波导 + 探测器
    ├── EIC (6nm 先进工艺): 驱动+控制电路
    └── 3D堆叠封装: EIC-on-PIC → CoWoS/SoIC集成
    ↓
[光引擎模块] → 耦合+测试 ← ⚠️ 良率瓶颈
    ↓
[交换机整机组装]
    ├── 交换ASIC (NVIDIA自研)
    ├── 外部激光源(ELS) ← 高功率激光器
    ├── 光纤连接单元(MPO/MMC)
    ├── 液冷散热系统
    └── 管理固件/软件
```

### 6B.2 关键瓶颈识别

| 瓶颈环节 | 瓶颈性质 | 严重程度 | 缓解时间 |
|:---|:---|:---:|:---:|
| **台积电COUPE产能** | 物理垄断 — 唯一量产硅光集成平台 | 🔴 极高 | 2027年前无替代 |
| **硅光引擎良率** | 工艺瓶颈 — 光/电/热多物理场耦合，晶圆级测试缺乏 | 🟠 高 | 2026-2027爬坡 |
| **外部激光源(ELS)** | 材料瓶颈 — 高功率+高可靠性CW激光器供应受限 | 🟡 中高 | 产能扩张中 |
| **光纤耦合对准** | 工艺瓶颈 — 亚微米级精度，单通道失效→整板报废 | 🟠 高 | 自动化提升 |
| **液冷散热** | 工程瓶颈 — ASIC+激光器共封装→功率密度飙升 | 🟡 中 | 液冷方案成熟 |

## 阶段6B扩展：对中际旭创/新易盛的竞争影响分析

### 核心问题：CPO是否会替代中际旭创和新易盛的传统可插拔光模块业务？

### 短答案：**不会，但会改变其业务结构和价值链位置。**

### 详细分析

#### 一、技术架构视角：CPO vs 可插拔 = 场景分工，非零和替代

```
数据中心网络拓扑:
┌──────────────────────────────────────────────┐
│  Scale-up (机柜内/跨背板)                      │
│  GPU↔NVSwitch↔GPU: NVLink铜缆 → CPO光互联     │
│  ← CPO首先替代的领域: AEC/DAC + 短距光模块     │
├──────────────────────────────────────────────┤
│  Scale-out (机柜间/跨机房)                     │
│  ToR↔Leaf↔Spine↔SuperSpine: 可插拔光模块       │
│  ← 可插拔仍是主流 (标准化/热插拔/成熟生态)      │
├──────────────────────────────────────────────┤
│  Scale-across (跨区域/跨DC)                    │
│  DCI连接: 相干光模块/开放光系统                 │
│  ← 可插拔维持主导                              │
└──────────────────────────────────────────────┘
```

**关键判断**: CPO首先冲击的是机内短距的AEC/DAC和背板互连，而非通用可插拔光模块。在scale-out场景中，可插拔凭借标准化、可热插拔、维护便利、成熟供应链，在未来3-5年仍将担当主力。（来源: Supplyframe四方维产业分析; 国盛证券GTC/OFC总结）

#### 二、中际旭创的应对和卡位

| 维度 | 现状 | CPO时代的定位 |
|:---|:---|:---|
| **传统可插拔** | 全球800G市占~40%, 1.6T 2026年出货805万只(东吴预测) | 3-5年内仍为核心收入来源，需求增速>30% |
| **硅光能力** | 自研硅光芯片，良率~95%，成本下降15% | 硅光能力是进入CPO供应链的入场券 |
| **CPO布局** | 已配合英伟达Quantum-X推出CPO原型进入试点 | CPO光引擎+配套可插拔模块(双轨) |
| **XPO/NPO** | TeraHop品牌在OFC 2026展出12.8T XPO + 6.4T NPO + OCS | 全技术路线卡位 |
| **产能** | 苏州月产能200万只 + 泰国月产能50万只 | 产能规模是AI客户首要筛选标准 |

**中际旭创的判断**: 
- ✅ **积极因素**: 英伟达采用"可插拔+CPO并行"的渐进式演进，不会突然切断可插拔订单
- ✅ 中际旭创已是英伟达最重要的800G/1.6T供应商(锁定~80%份额)，深度绑定关系使其有"缓冲期"
- ⚠️ **长期风险**: 如果CPO从scale-up延伸到scale-out(2028+ Feynman平台)，高价值模块的TAM可能被压缩
- ⚠️ 但中际旭创正在从"光模块厂"向"光电系统方案商"转型(OCS/NPO/XPO全覆盖)

#### 三、新易盛的应对和卡位

| 维度 | 现状 | CPO时代的定位 |
|:---|:---|:---|
| **传统可插拔** | 800G可观份额，1.6T通过头部认证，2026年放量 | 3-5年核心收入 |
| **全技术路线** | VCSEL/EML + 硅光 + 薄膜铌酸锂全覆盖 | 多技术路线降低单一路线风险 |
| **CPO布局** | 已布局CPO产品，OFC 2026展出OCS/NPO/XPO全栈 | CPO/NPO/XPO三线并行 |
| **制造纵深** | 泰国工厂一期已投产，二期在建 | 地缘风险对冲+关税规避 |
| **AEC/AOC** | 已布局高速AEC电缆模块 | 补全产品矩阵 |

**新易盛的判断**:
- ✅ **独特优势**: 全技术路线+泰国制造纵深 = 应对不确定性的最佳组合
- ✅ OFC 2026首次展出OCS交换机(NX200/NX300)，从模块向系统级延伸
- ⚠️ 与中际旭创相比，英伟达绑定深度稍弱(份额第二)
- ⚠️ 但多客户结构(谷歌/Meta/微软)降低了单一大客户风险

#### 四、竞争格局总结

| 维度 | 中际旭创(300308) | 新易盛(300502) | NVIDIA CPO |
|:---|:---:|:---:|:---:|
| **2026年1.6T出货** | ~805万只(全球第一) | ~302万只(全球第二) | Mellanox ~287万只 |
| **CPO集成度** | 光引擎配套供应商 | 光引擎+NPO方案 | 全栈自研(ASIC+光引擎) |
| **价值链位置** | 从模块供应商→系统方案商转型中 | 从模块→OCS/系统延伸 | 系统定义者 |
| **英伟达绑定** | 极深(80%份额) | 较深(第二供应商) | — |
| **CPO冲击敞口** | 中(有缓冲+已布局) | 中低(多客户+全路线) | — |
| **3年收入影响** | 可插拔持续增长，CPO配套增量 | 可插拔增长+系统级新收入 | CPO快速放量 |

#### 五、核心结论

**对中际旭创和新易盛，NVIDIA Spectrum-X CPO量产不是"颠覆"，而是"场景重新分配"：**

1. **短期(2026-2027):** 可插拔光模块需求仍在爆发(800G/1.6T出货量翻倍)，CPO仅在超大规模集群的scale-up场景渗透。两家公司的传统业务增速不会受CPO拖累。

2. **中期(2027-2028):** CPO从scale-up向部分scale-out延伸。中际旭创/新易盛的NPO/XPO方案将填补传统可插拔与完全CPO之间的"中间地带"。**关键是：谁能从"模块供应商"升级为"光电系统方案商"。**

3. **长期(2028+):** 如果Feynman平台实现CPO全面渗透scale-out，可插拔TAM可能收缩。但这是3年+的时间窗口，且两家公司已明确布局OCS/CPO/硅光全栈。

4. **最危险的其实是二线光模块厂商(没有CPO布局、没有硅光能力、没有英伟达深度绑定)，而非中际/新易盛。**
